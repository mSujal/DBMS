# Hotel Management System
---
The project is design of database system for a hotel management system normalized upto Third Normal Form with minimal HTML, CSS and JS frontend with Flask backend.

## To run locally
1. Create virtual environment
```bash
python -m venv env 
source env/bin/activate     # Linux/MacOS
# OR
env\Scripts\activate        # Windows
```

2. Install dependencies
```bash
pip install -r requirement.txt
```

3. Setup MySQL server locally and create user profile

4. Create .env file 
```python
USERNAME = <user_name>      # USERNAME = sujal
PASSWORD = <password>       # PASSWORD = password123
```

5. Run server.py 
```bash
cd Backend 
python server.py 
```

6. Launch the HTML file in browser of choice manually or running command using firefox
```bash
cd Firefox 
firefox index.html 
```
